# 多来源工作信息汇总产品

## 项目简介

这是一个多来源工作信息汇总产品，用于整合来自邮件、日历、项目管理工具和任务系统的工作信息，帮助用户更好地管理工作任务和时间。

## 技术栈

### 后端
- Node.js
- Express.js
- 内存存储（模拟MongoDB）
- JWT认证

### 前端
- React
- React Router
- Ant Design
- Tailwind CSS

## 运行项目

### 前端运行

1. 进入前端目录
```bash
cd frontend
```

2. 安装依赖
```bash
npm install
```

3. 启动开发服务器
```bash
npm run dev
```

4. 打开浏览器访问 http://localhost:5173

### 后端运行（可选）

如果需要运行后端服务，可以按照以下步骤操作：

1. 进入后端目录
```bash
cd backend
```

2. 安装依赖
```bash
npm install
```

3. 启动服务器
```bash
npm start
```

4. 后端服务将运行在 http://localhost:3000

## 登录说明

由于是模拟环境，您可以使用任意邮箱和密码进行登录或注册。系统会自动创建一个模拟用户。

## 功能说明

1. **登录/注册**：用户可以通过邮箱和密码进行登录或注册
2. **仪表盘**：显示工作信息统计和最近的工作信息
3. **数据源管理**：添加、同步和删除数据源
4. **工作信息管理**：查看和管理来自不同数据源的工作信息
5. **设置**：修改用户偏好设置

## 模拟数据

为了方便演示，系统内置了以下模拟数据：

### 仪表盘
- 总任务数：2
- 已完成任务：1
- 即将到来的会议：2
- 待处理的截止日期：1

### 数据源
- 个人Gmail（邮件）
- 公司Outlook（邮件）
- 项目Jira（项目管理）

### 工作信息
- 完成项目规划（任务，已完成）
- 团队周会（会议，待进行）
- 提交项目报告（截止日期，待处理）
- 代码审查（任务，进行中）
- 客户演示（会议，待进行）
- 修复bug（任务，进行中）

## 注意事项

1. 本项目使用内存存储，数据会在服务器重启后丢失
2. 前端使用模拟数据，无需后端服务也能正常运行
3. 登录和注册功能使用本地存储，无需真实后端验证
4. 所有功能都已模拟实现，可以正常体验完整的用户流程
